Télécharger Optizien (environ 16 Mo)

Première installation

  1. Clic droit sur le fichier téléchargé → Extraire tout → choisissez le Bureau → Extraire.
  2. Ouvrez le dossier Optizien, double-cliquez sur Ouvrir Optizien.
  3. Cliquez sur Installer les composants et suivez les cartes du panneau.
  4. Carte Options → Mises à jour en ligne : saisissez le même identifiant et mot de passe que pour cette page. Les versions suivantes arriveront toutes seules.
